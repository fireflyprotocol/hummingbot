# MarketStatus

`cancel_only` is a reopen state, not a failure state: a market coming back from a halt passes through it so makers can pull stale quotes before trading resumes. 

## Enum

* `ACTIVE` (value: `'active'`)

* `CANCEL_ONLY` (value: `'cancel_only'`)

* `HALTED` (value: `'halted'`)
